# Feste Plätze für weitere Villen (Paper): Vier Freunde kommen nacheinander, jeder bekommt den nächsten Rasterplatz um die
# erste Villa. Die Straßen zu den ersten Villen fahren um die noch freien Plätze herum, damit keiner wegen einer Straße
# verworfen wird. Auswertung: Serverprotokoll („verworfen“) und plugins/StinkendReich/strassen.json.
# Aufruf: CHAT_AUS=1 tools/ingame/paper.sh tools/ingame/szenarien/paper_plaetze.txt
merke anfang
bis 120 Baustelle: Villa 0 fertig
warte 3
merke
server @/villa nachbar Max
bis 300 Baustelle: Villa 1 fertig
merke
server @/villa nachbar Anna
bis 300 Baustelle: Villa 2 fertig
merke
server @/villa nachbar Otto
bis 300 Baustelle: Villa 3 fertig
merke
server @/villa nachbar Lena
bis 300 Baustelle: Villa 4 fertig
# (ab Serverstart suchen: Lenas Straße kann schon fertig sein, bevor ihre Villa gemeldet ist)
merke anfang
bis 900 Straßen: .*Lena.* fertig
warte 3
server @/villa strassen
