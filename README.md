## ✨ Funktionen (geplant)

| | Funktion | Kurz |
|---|---|---|
| 🏛️ | **Villa am Spawn** | Die „Super Safe Modern Mansion“ wird beim ersten Betreten einer Welt am Spawn platziert, auf einer eigens geebneten Fläche. |
| 🔐 | **Über 25 Mechanismen** | Sicherheitssystem mit Stufen und Lasern, Zugangskarte, Passwort-Tür, Aufzüge, Schmuck-Tresor mit Fallen, Überwachungsraum mit Kameras und mehr. Neu gebaut als eigene Blöcke, funktionieren für jeden Spieler. |
| 🤵 | **Butler** | Folgt dir oder bleibt zu Hause, holt Erz, Holz, Kohle und Essen, kocht und sortiert Truhen. Optional per Chat mit Claude steuerbar. |
| 🏎️ | **Bonzenauto** | Fahrbares Luxusauto mit Beschleunigung, Drift, Hupe, Scheinwerfern und Kamera-Optionen. |
| 🔄 | **Update-Funktion** | Die Mod meldet neue Versionen aus den GitHub-Releases und lädt sie auf Wunsch. |

## 📦 Installation

Folgt mit dem ersten Release. Pro Minecraft-Version gibt es eine eigene `.jar`.

## ⚖️ Hinweis zur Villa

Die Villa basiert auf der Map [„Super Safe Modern Mansion“ von chamo572](https://www.planetminecraft.com/project/super-safe-modern-mansion/). Die Map selbst und alle daraus erzeugten Strukturdateien sind **nicht** in diesem Repo und nicht in den Releases enthalten, weil die Nutzungsbedingungen des Erstellers einen Re-Upload verbieten.
